AIF1303 AI Fundamentals · Final Project · Topic 02, Mini Campus Delivery Robot

Go now, or wait for the snowplow?

A courier robot must bring a parcel from the dormitory to the AI Lab. The short way crosses an open courtyard that snow can block, and the only snow sensor is noisy. Three course algorithms work together to make one decision.

  1. 1A* searchplans the shortcut and the fallback. Their lengths become the MDP rewards.
  2. 2Bayesturns the forecast and a noisy reading into P(Blocked).
  3. 3MDPvalues Move and Wait. The belief weights them and the robot picks the larger.

    Input

    The MDP weighs a quick delivery against getting stuck, and counts what can happen while waiting (snowplow or new snow).

    Evaluation: does the agent beat simple rules?

    Simulated mornings with a hidden true state, seed 2026. always_move leaves at once, trust_sensor waits on SNOW and moves on CLEAR, agent uses Bayes and the MDP. Every policy moves after 10 waits.

    Run the simulation to compare the three policies. Your current setup is added as a fourth scenario.

    Higher reward is better. Rewards here are undiscounted. "Stuck rate" means the robot met a blocked courtyard and took the fallback, not a failed delivery. The simulator uses the same assumed model as the agent, so it checks the decision logic, not real-world accuracy.

    About this project

    QarJol is a classroom simulation. The map is a hypothetical 6×6 campus, and every probability, reward and time is an assumption chosen to make the decision interesting, not a measurement.

    Run it yourself

    python app.py        # this web interface
python main.py       # console version
python -m unittest discover -s tests -v

    Python 3.9+, standard library only. The web page calls the same qarjol functions as the console; online, they run in the browser through Pyodide.

    Limitations

    • Probabilities would need real sensor and snow-clearing data.
    • Only one passage can be blocked, and snow does not change during the delivery.
    • Weighting the fully observed MDP's Q values by the belief approximates a POMDP.
